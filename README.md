# Módulo 1: Registro de Animales y Tutores (TI3043 - FB50-C1)

Prototipo del Módulo 1 del Sistema Municipal de Tenencia Responsable de Mascotas, desarrollado con Node.js, Express y MongoDB, integrado al Núcleo de autenticación y catálogos.

## Requisitos previos
- Node.js 18 o superior
- Instancia de MongoDB (local o MongoDB Atlas)

## Ejecución local
1. Clonar el repositorio e instalar dependencias:

   npm install

2. Copiar .env.example a .env y configurar MONGO_URI.

3. Iniciar el servidor: 

   npm start

4. Abrir en el navegador http://localhost:3000.
